# Северная Волна — новая главная страница

## Состав архива

- `index.html` — итоговая версия главной страницы (один файл: стили, скрипты и логотип внутри).
- `versions/v3-svetlaya-pervaya-versiya.html` — предыдущая версия, для сравнения.
- `assets/logo.svg` — логотип-медведь в векторе (#9C2835).
- `assets/image-urls.txt` — список фото с nordwave.ru, которые использует страница.
- `chat.md` — история запросов и решений из чата.

## Что сделать перед запуском

1. **Фото.** Сейчас они подгружаются по ссылкам с nordwave.ru. Скачайте их по списку из `assets/image-urls.txt`, положите в папку сайта и замените ссылки в `index.html`.
2. **Формы.** Окно заявки и форма в контактах пока только показывают «Спасибо» и никуда не отправляют данные. Подключите отправку на почту или в CRM: в коде это места с пометкой `TODO`.
3. **Ссылки.** Укажите адреса страниц каталога, статей и политики обработки персональных данных (сейчас они ведут на `#`).
4. **Тексты.** Проверьте формулировки и условия акции «−10% на первый заказ».
